# K90 / Android 16 真机验证

这些是待执行的测试步骤，不代表已经在手机上测试通过。

## 独立动作

- [ ] 前台“振动测试”：立即开始循环，约 5 秒后停止。
- [ ] 测试过程中点击顶部“停止报警”：声音、振动都及时停止。
- [ ] 前台“响铃测试”：使用闹钟音量，约 5 秒后停止。
- [ ] 停止时间选“手动”，在工具页开始“完整报警测试”，锁屏后超过 1 分钟仍持续；通知停止按钮可结束。
- [ ] 仅振动模式、仅响铃模式、同时开启三种组合分别验证。
- [ ] 完成一次测试后重复测试，不残留音频、不重复叠加、不出现无法停止的振动。

## 短信链路

- [ ] 添加关键词“告警”，开启监听；从不在通讯录的号码发送“设备告警”，触发报警。
- [ ] 发送无关短信，不触发；日志说明未命中。
- [ ] 排除词“已恢复”，发送“告警已恢复”，不触发。
- [ ] 多关键词“全部”模式：只包含一个不触发，全部包含才触发。
- [ ] 长短信的关键词出现在后半段，仍能触发；日志只记录分段数和结果。
- [ ] 双 SIM 分别接收短信；同样内容的新短信不被错误去重。
- [ ] 报警过程中又来匹配短信：合并提醒，不创建多个播放器，不延长设定停止时间。
- [ ] 暂停监听后再发匹配短信，不触发。

## 后台与恢复

- [ ] 回到桌面后发送匹配短信，能触发。
- [ ] 锁屏 5 分钟后发送匹配短信，能触发。
- [ ] 从最近任务中划掉应用，再发短信，验证厂商行为。
- [ ] 重启并解锁一次后，不主动打开应用，发送匹配短信。
- [ ] 验证静音/勿扰/省电模式的实际表现，记录设置与诊断信息。
- [ ] 系统强行停止后不应承诺接收；重新打开后验证恢复。
- [ ] 撤销短信权限，首页提示权限缺失；重新授权后恢复。
- [ ] 关闭通知渠道，首页提示；恢复渠道后验证通知停止入口。

失败时保存应用诊断和日志；振动失败时在测试仍进行中保存 `dumpsys vibrator_manager`。区分“未收到短信”“规则未命中”“服务启动失败”“系统未执行振动”，不要仅根据 Android 版本推定根因。
